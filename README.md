# صفحة تحميل مساعدي للأندرويد

مجلد مستقل يحتوي على صفحة عربية متجاوبة ونسخة APK الحالية ومعلومات التحقق منها. لم يُنسخ أي ملف برمجي أو أصل من المشروع المرجعي؛ استُخدمت فكرة حزمة الإصدار المحلية فقط.

## التشغيل محليًا

من داخل هذا المجلد:

```powershell
python -m http.server 8765
```

ثم افتح:

```text
http://127.0.0.1:8765/
```

يمكن أيضًا فتح `index.html` مباشرة، لكن تشغيل خادم محلي يتيح اختبار المشاركة والتنزيل بصورة أقرب للاستضافة الحقيقية.

## الملفات

- `index.html`: محتوى الصفحة وجميع مواصفات وخدمات التطبيق.
- `styles.css`: التصميم المتجاوب للجوال والكمبيوتر والوضع العرضي.
- `assets/`: أيقونة التطبيق والصور الأصلية من تطبيق مساعدي.
- `releases/`: ملف APK وبصمة SHA-256 وأداة التحقق.

## النشر

المجلد ثابت ولا يحتاج إلى بناء. ارفع محتوياته كما هي إلى أي استضافة ملفات ثابتة مع الحفاظ على المسارات النسبية. رابط التنزيل داخل الصفحة:

```text
releases/Masaeedi-v1.2.3-universal.apk
```

يفضل أن يرسل خادم الاستضافة ملف APK بنوع المحتوى:

```text
application/vnd.android.package-archive
```

## تحديث الإصدار

عند استبدال APK:

1. حافظ على اسم الحزمة ومفتاح التوقيع كي يعمل التحديث فوق النسخة المثبتة.
2. حدّث الاسم والحجم والإصدار في `index.html`.
3. أعد إنشاء SHA-256 داخل `releases/SHA256SUMS.txt`.
4. شغّل `releases/verify-apk.ps1`.
